# 실로폰 타일

초등학생 실로폰 합주 연습용 화면입니다. 피아노 타일 게임처럼 음이 박자에 맞춰 떨어지고, 큰 채가 올라갔다 내려오며 칠 순간과 손(왼손/오른손)을 보여 줍니다.

- 곡: 오버 더 레인보우, 다이너마이트 (동아리 악보집 2021)
- 메트로놈과 빠르기 조절, 구간 반복, 늘임표 (선생님 신호 / 자동 이어가기)
- 원곡 반주 파일 불러오기 (브라우저에만 저장, 서버로 올라가지 않음)
- 계이름 가리기 (보이기 → 떨어지는 음만 → 모두)

## 쓰는 법

서버가 필요 없는 HTML 파일 하나입니다. `index.html`을 브라우저로 열거나 GitHub Pages 주소로 접속하면 바로 쓸 수 있어요.

단축키: Space 시작/멈춤, ↑↓ 빠르기, ←→ 시작 마디, M 메트로놈, N 음 소리, H 계이름 가리기, F 전체 화면
